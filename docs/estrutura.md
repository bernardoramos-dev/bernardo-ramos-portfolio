# Como este repositório se conecta ao portfólio

O site em [bernardoramos.com.br](https://bernardoramos.com.br) é a experiência pública principal: apresenta a identidade visual atual, os projetos e as demonstrações navegáveis.

Este GitHub funciona como uma extensão editorial do site. Cada case dá mais contexto ao projeto e aponta o que as capturas comprovam. O repositório não é uma cópia desatualizada do site nem o pacote usado para publicar suas páginas.

## Mapa

```text
README.md             Apresentação e atalhos para explorar o trabalho
assets/cases/         Capturas identificadas por projeto
assets/social/        Capa azul usada nesta página do repositório
cases/                Quatro estudos de caso em destaque
cases/archive/        Outros projetos documentados
docs/                 Estrutura, evidências e índice das imagens
```

## Onde encontrar cada coisa

- Para navegar pelos projetos e demos, comece no [site publicado](https://bernardoramos.com.br).
- Para entender decisões, contexto e contribuição, abra o [índice de cases](../cases/README.md).
- Para localizar imagens e conhecer seus limites, consulte o [índice visual](imagens.md).
- Para saber o que é real, protótipo ou demonstração, consulte as [convenções de evidência](evidencias.md).

## Atualizações

Ao atualizar este repositório, preserve a identidade visual vigente do site e mantenha os cases alinhados ao estado real dos projetos. Atualize capturas somente a partir de arquivos revisados e identifique protótipos, demos e contribuições de terceiros com clareza. O site e suas publicações são mantidos separadamente.
