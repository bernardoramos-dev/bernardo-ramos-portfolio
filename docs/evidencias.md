# Como interpretar as evidências

Este repositório reúne capturas e relatos para apresentar projetos de Bernardo Ramos. Cada case diferencia o produto real, o protótipo, a demonstração e o material editorial.

## Convenções

- **Captura real:** tela do site publicado ou do protótipo de app identificado no texto.
- **Demonstração:** interface explorável preparada para mostrar um fluxo. Os dados podem ser fictícios; isso fica indicado no case.
- **Arte editorial:** imagem criada para a direção visual do portfólio. Não é uma interface nem um recurso do produto.
- **Link externo:** abre um site publicado e leva à experiência real disponível naquele endereço.

## Limites importantes

- TradeFlow representa o fluxo de trabalho em uma demonstração com dados fictícios. O repositório não contém dados, telas internas ou integração com sistemas da L’Oréal.
- Suma, Casa TV e Mercúrio são protótipos de produto; as capturas mostram suas interfaces reais. A navegação web do portfólio não é o aplicativo nativo.
- A captura da Controllist mostra a página e a marca reais, mas mantém o aviso que o próprio site exibe: ambiente de validação, dados demonstrativos e sem uso em produção.
- ESPM Tech Week documenta a idealização e a identidade visual criadas por Bernardo com apoio de IA. A implementação do site foi feita por um amigo.
- Hulkinho organiza o pedido antes da conversa. A compra e o frete são confirmados no WhatsApp; a demonstração local não envia mensagens.
- Nenhuma métrica de economia de tempo, receita ou conversão é declarada sem uma fonte confirmável.
